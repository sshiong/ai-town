# 选择性分块备份携带签名冷文件

`ai-town-selective-archive` 的可选 coldHistoryFiles 表在选择性导出的独立检查点中携带原文件实体；部署私有 storageId 不进入可携带包。原 manifest、公钥、签名、文本、消息 UUID 和时间保持不变。旧包没有该表时继续兼容；含新表的包需要本版导入器。

只携带同时属于所选居民、canonical memory 与完整原文集合的文件。时间或类别筛选不得自动扩大范围，也不能裁切文件后继续声称保留原签名。manifest、作业状态及管理界面显示包含数和三类排除数：未选择对应记忆、所选范围不含完整原文、未选择对应历史类别。memories-only 仍可独立导出完整 canonical 文本，不要求未选择的历史正文可用；要求会话/旅行原文的范围缺少源原文时明确失败，不能成功导出空历史。

导入在目标改写前核验外层包、冷文件签名/摘要及与包内原文、居民、世界和作者图的精确对应。跨预检分页的相同当地历史范围不能重复发布。恢复沿原 ID 映射重建查询索引，保留原签名文件，旅行分页中的全局作者也按对应居民映射。冷档索引与物理存储引用进入私有回滚快照；发布响应丢失保留可能已提交实体，取消部分应用恢复原索引与文件，不能删除尚未确定未引用的对象。

两套选择性事务测试 37 项通过，其中 9 项新增覆盖完整携带与原样再导出、时间/类别排除、独立记忆导出、缺实体恢复续作、缺必需原文拒绝、内部签名/原文不符写前拒绝、冷档发布后取消、旅行作者映射、跨页重复范围及发布回执丢失。全量 43 组、558 项通过，Convex TypeScript、前端构建与目标 lint error 检查通过。真实 B→新隔离 E 镇的选择性克隆已通过，范围见下节；这些证据不替代完整故障/压力矩阵。

每份冷文件仍受 1000 条消息、900000 字节约束，编码后的单块也受原分块上限约束，超限拒绝而不截断。全部热原文继续保留，尚未实现超大单段冷历史分块、热冷腾挪、真实压缩或外部冷存位置接入。

## 本机真实选择性克隆

2026-10-10，B 的选定居民按 agent-one 全部历史类别、无时间限制导出 28 分块/197 记录（15 条 canonical memory），自动携带一份原先由 C 签名的 10 条/2622 字节原生日常冷文件。独立 Node 核验外层 manifest、每块摘要及原文件 Ed25519 签名/正文摘要通过。

E 使用独立本机 Convex 数据库与新小镇身份，居民、身体、Agent 与 memory 全部重映射；显式绑定同一本机 qwen3.5:4b 配置，Embedding 为 qwen3-embedding:0.6b、1024 维且 fingerprint 相同。从目标 canonical 历史入口发现/读取后，源消息 UUID、正文、作者与原时间逐项一致，再导出与原 C 文件深度全等。父任务独立重跑只读后验检查再次通过。

同一真实源的 memories-only 包包含完整 canonical 文本，冷文件 included=0/未选历史类别=1；history 包包含选择的热历史，冷文件 included=0/未选对应记忆=1，不扩大 scope。B 原居民、模型与绑定一致，联邦及引擎运行状态已恢复。E 仅用于隔离验收，保持联邦关闭、世界暂停、无邻居；D 原 7182 记录大型克隆验收数据未改动。私有 600 权限证据 selective-cold-live-proof.json 与 selective-cold-postverify-proof.json 不入仓库，不包含在公开下载中。
