## 已实现的行为

时间配置有界且每趟旅行持久保存安全返乡边界。缺少持久时钟证据、有回拨或观察间隔异常时，访问准入、续租及 Host 动作保持锁定；管理员确认 UTC 后可先按保存期限安全返乡，访问全部结束后再完整解锁。历史补传仍须签名、身份、代数和幂等校验。测试包含缺失 clock、租约边界、续租及分步恢复。

Direct 支持最多四个签名 HTTPS 候选入口及优先级。网络失败可有限切换，使用备用业务入口前须验证同一可信身份；身份、凭证或代数错误不得转向其他主机。丢失 ACK 的重试保留原事件标识。恢复和迁移清除旧入口集合，事务提交继续检查凭证及地址代数。

管理员可按居民全局 ID 拒绝新的访问，拒访策略适用于预约、排队和晋升，不破坏已授权访问的续租和清理。普通、大型和显式配置导入验证策略容量并保留作用域；居民选择性导入不携带 Host 拒访策略。

旅行状态变化写入持久审计，按访问与时间分页查询；导入历史不冒充新发生事件。抵达与离开使用原像素场景内的短暂效果，遵守减少动态效果偏好；away 居民仍可查看公开介绍与本地历史。该轮未完成浏览器视觉验收。
