# 记忆来源真实验收（2026-10-11）

隔离 D/E 验收使用非默认、停止的 synthetic 世界和专用 synthetic 居民。临时管理员 fixture 只提供固定合成观察、所有权检查与脱敏检查结果；压缩、纠正、签名导出、居民恢复和合并均调用正式生产接口。fixture 与私有执行脚本不加入产品代码，原世界与原居民保留。

本次真实聊天调用使用已注册的 Ollama `qwen3.5:4b`，synthetic 居民直接绑定既有配置。现有 `qwen3-embedding:0.6b` 活动空间保持不变。D 的既有 DISABLED 联邦身份、E 的既有 ACTIVE 身份均未修改；停止世界的记忆操作和签名居民导出不需要游客准入。E 没有全局主聊天配置，因此验收没有为 fixture 设置或切换全局主配置。

## 实际通过的链路

| 步骤 | 实际结果 |
| --- | --- |
| 批量压缩 | 正式异步任务完成 1 批、4 份来源，生成 2 份摘要；4 份原文及其内容摘要保持不变，来源 claim 全部 DONE，没有遗留 CLAIMED。 |
| 来源证明 | 压缩后的 2 份摘要最初均为 current；均有 subjective 标记及 MODEL_ESTIMATE 置信度类型，摘要来源覆盖全部 4 份原文。 |
| 管理员纠正 | 正式 appendCorrection 追加 1 份纠正记录，使 1 份关联旧摘要不再 current；原观察保持保留，没有用纠正覆盖原文。 |
| 签名居民导出 | 正式 exportResident 返回带签名的 resident bundle，包含 6 份记忆和 2 份摘要来源证明。 |
| 同居民恢复 | 先执行正式 preflight，再使用其目标摘要和确认信息执行 D 的 resident restore；原文 ID、原文内容、纠正记录及关联摘要 stale 状态保持，恢复导入记录已生成。 |
| 跨镇合并 | 正式 merge 导入 E 的 synthetic 目标世界；全部原来源记忆 ID 重映射到目的地，居民全局所有权变为目的地，4 份原文和纠正记录保持，1 份 stale 摘要仍 stale，没有遗留 CLAIMED。 |
| 原配置不变 | D/E 验收前后的 modelSettings 摘要相同；验收前已存在的居民绑定摘要相同。 |

首轮模型连接因本机模型桥接未监听而失败。桥接恢复后，生产任务按既有退避与调度自然重试并完成；未清除任务、claim 或模型 permit。居民恢复沿用正式静止与目标摘要门禁，没有绕过检查或清除其他居民工作。

## 验证边界

此结果证明上述 synthetic 数据经过了真实模型压缩、正式纠正与来源失效、签名居民导出、同居民恢复和跨镇合并；不是仅以 fixture 准备、类型检查或单元测试推断通过。私有证明只保存模型标识、数量、哈希及固定结果码；仓库不记录私有运行标识、所有者标识、原文、bundle 或凭据。

本次没有验收完整向量复用或兼容性认证，也没有断言向量跨镇复制、重建任务完成或检索质量。活动 embedding 配置保持不变不能作为这些项目已通过的证据。本次也不覆盖浏览器完整操作流程、服务器重启续作或真实居民历史的长期运行。
