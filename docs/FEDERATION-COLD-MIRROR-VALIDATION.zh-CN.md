# 外部冷归档镜像实现与验收（2026-10-11）

管理员在冷归档页选择服务器环境预先配置的 S3 目标，保存启用状态并执行上传/读回探测。随后从分页已验证归档列表选择原件，创建镜像任务；每次推进一个分块，全部分块确认后才上传原签名清单。v1 则上传包含完整原件的单文件。任务记录配置/身份/归档绑定、已确认游标和字节数，失败可重试相同对象键。取消围住后续提交，不删除已经上传的远端对象。本地归档和热历史均不由此流程删除。

目标由服务器 `COLD_ARCHIVE_S3_CONFIG` JSON 数组配置，每项包含 name、endpoint、region、bucket、prefix、accessKeyId、secretAccessKey，以及可选 sessionToken。endpoint 必须是没有路径、查询、凭据的 HTTPS origin，prefix 不能含目录穿越。凭据只留在服务器环境，不通过界面输入、不随归档/备份导出。内网 S3 仍需部署管理员在 `FEDERATION_PRIVATE_NETWORK_ALLOWLIST` 精确批准私网 CIDR；该配置不会创建路由或信任无效证书。存储服务需配置私有 bucket 与最小所需读写权限。

每次 Node 请求核验全部 DNS 结果并固定 socket，保留 Host/SNI/TLS 校验，不跟随重定向。S3 SigV4 对正文哈希签名；单对象输入/输出最多 2 MB，请求超时 30 秒。上传必须逐字节读回一致才记录成功；对象键按本镇身份范围、任务 runId、part/root 隔离。服务器凭据/目标配置变化、部署身份变化或本地归档变更都拒绝旧任务继续提交。缺失对象、提供商失败保留当前进度。重新配置需再次验证，取消中的请求可能留下远端对象，界面明确说明该边界。

自托管执行器未必继承外部 NODE_EXTRA_CA_CERTS。私有 CA 可由服务器配置可选 `FEDERATION_EXTRA_CA_CERTS_PEM`：只接受不超过 64 KiB 的 CERTIFICATE PEM 链，经过 X509 和 TLS context 解析，追加到默认根证书。联邦 HTTPS 与冷归档请求共用该信任配置；浏览器和归档不能提交 CA，不接收私钥，仍强制证书身份检查和 `rejectUnauthorized:true`。这不改变目的地 CIDR 核验或允许危险网段。
