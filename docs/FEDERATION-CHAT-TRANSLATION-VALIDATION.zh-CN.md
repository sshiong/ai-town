# 对话中文翻译验收（2026-10-11）

设置中选择简体中文后，对话区使用当前 Main Chat Profile 生成中文译文，可展开查看英文原文。英文界面不提交翻译请求。居民与访客生成对白明确保持英文；翻译存放在独立缓存，原消息、角色记忆、联邦传递内容及像素画风保持原机制。

首次打开中文对话翻译最近 20 条；“翻译更早的消息”每次追加 20 条。开启中文翻译的世界后续新英文消息由后台调度，无需停留在该对话。自动窗口中较早已完成译文保留显示缓存并退出订阅，未完成消息及原文变化继续监听。中文原消息不重复翻译。

翻译使用已有本机 Ollama qwen3.5:4b，仅翻译请求关闭思考输出，Embedding 不变。翻译逐条排队并复用缓存，复用现有模型用量与并发限制；拒绝空内容、截断、推理及无中文输出。失败保留原文，按服务端退避时间提供有限重试。原文变更后旧译文失效；后台使用源摘要及任务租约防止过期结果写回。

输入与输出上限各 8 KiB，翻译队列最多 200 条、单会话 100 条，缓存最多 5000 条；遵守现有存储预算和缓存保留期。长历史需分批加载，翻译速度与准确性取决于当前模型。已含中文的消息按原文显示。
